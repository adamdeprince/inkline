# Inkline 0.2.0 — release candidate notes

This version adds Folio shortcuts, a Settings panel and six independent terminal
slots. The ARM bundle is built locally; publication awaits the device test run.
The public download remains 0.1.0.

Hold **right Alt/Option** with:

- **1–0** for F1–F10; **Tab** for Escape; **Up/Down** for PageUp/PageDown.
- **Left/Right** to move among six terminals, opening a shell in an unused slot.
- **Space** for Settings; **Backspace** for a prompt to quit all terminals.

Settings is the fifth bottom button. It offers a saved choice between Caps Lock
and Control, with Control as the default. **Ctrl+Shift+B** hides or restores the
bottom bar. **Ctrl+Shift+Q** and the Quit button also ask for confirmation;
Cancel is selected initially. Exiting one shell leaves other terminals running.

Each terminal keeps its own screen, scrollback, graphics and PTY. Inactive
terminals continue receiving output. Memory limits are applied per terminal,
and unused slots do not allocate a terminal. Settings writes occur only when a
preference changes. Updates preserve an already running Inkline session; quit
and reopen once to use the new version.

All seven host suites and the ARM build pass. The shortcut and session suites
also pass with address/undefined behavior sanitizers. Folio/USB hardware checks
and the seven ARM suites are pending while the tablet's SSH connection is down.
The existing kitty and sixel compatibility limits still apply.
