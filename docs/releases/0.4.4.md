# Inkline 0.4.4 preview

Typewriter is now a RAM-backed local editor. Manual typing edits the document
and sends committed characters while live USB output is active. **Files & send**
loads and saves UTF-8 under any filename, selects 5, 10, 20, 40, or 80
characters per second, sends the complete document in bounded chunks, and stops
an active send. **Exit typewriter** clearly returns to USB Settings.

Editing, selection, scrolling, and USB acknowledgements do not save the
document. Save writes explicitly. Normal Inkline shutdown writes a changed
named document or uses `~/.inkline-typewriter-draft` for an untitled recovery
copy. The editor supports clipboard operations, pen/finger selection, and
two-finger scrolling. The public sender command is `keyboard-send`;
`inkline-type` and `~/inkline type` remain compatible.

Inkline now privately loads Noto Sans Symbols 2 and GNU Unifont/Unifont Upper
after its existing terminal and CJK faces. These OFL-licensed fallbacks add
common monochrome symbols, broad BMP coverage, and many supplementary scripts
without a system font installation or font-cache writes. They add about
11.5 MiB installed. Rare and private-use characters can still need a specific
font.

Host tests cover RAM-only editing, explicit save and exit persistence, arbitrary
filename extensions, hidden recovery, selectable sender speed, bounded
whole-document transfer, command aliases, font loading, and the existing
terminal, USB, shortcut, input, graphics, and license behavior.
