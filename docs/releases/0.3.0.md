# Inkline 0.3.0 preview

This release adds Asian input, a RAM clipboard, text selection, and live font
resizing for reMarkable 2 on firmware 3.27.3.0. Install the ARM bundle using the
[installation procedure](https://github.com/adamdeprince/inkline/blob/v0.3.0/docs/install.md).
An update preserves open terminals; quit and reopen Inkline to activate it.

- **Settings:** solid fill and a filled circle identify the active value;
  a dashed outline identifies keyboard focus. Caps Lock/Control and Shown/Hidden
  are explicit choices. Open with right **Option+Space** or the fifth bottom button.
- **Text size:** **Option +/−**, two-finger pinching, or Settings resize all six
  terminals from 16 to 48 pixels. Shells stay running. The new size is saved
  after a gesture finishes or key repeats pause, without per-motion disk writes.
- **Selection and clipboard:** drag a finger, pen, or mouse; right **Option+C/V**
  copies and pastes. Unicode and soft-wrapped lines copy correctly. The shared
  128 KiB UTF-8 clipboard stays in RAM and supports OSC 52 and kitty clipboard
  paste events. It is separate from the notebook application's clipboard.
- **Cut:** Option+X copies the selected terminal output and explains that the
  editor must delete document text. OSC 52 alone cannot perform an editor's cut.
- **Input methods:** choose Romaji (hiragana), Pinyin, basic Zhuyin, Wubi 86, or
  US-International through Settings. Space/Enter, number keys, or a tap select
  candidates. The methods and dictionaries come from GoblinView. A private
  Noto CJK font makes Chinese and Japanese text readable on stock firmware.
- **GoblinView:** the companion utility has a new September 14 source snapshot
  and defaults to `-m` inside Inkline. Outside Inkline, `goblin-view -m` selects
  monochrome explicitly. Its download and instructions are on the
  [utilities page](https://inkline.goblinreactor.com/utilities.html#goblin-view).

All nine host and ARM suites pass. The affected host suites also pass with
address and undefined-behavior sanitizers. Tests cover rotated pinch events,
font persistence, independent PTYs, finger selection between terminals, OSC 52,
paste modes, Unicode reflow, candidate selection, and all five input methods.
The tablet's offscreen Qt renderer displays the new Settings and CJK candidates.
GoblinView passes its six upstream ARM suites, client/server smoke test, and
real-PTY checks for explicit and automatic monochrome output.

Physical Folio/USB, pinch, and pen acceptance checks remain. Existing kitty
placeholder/animation and sixel compatibility limits still apply.
