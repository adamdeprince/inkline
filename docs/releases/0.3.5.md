# Inkline 0.3.5 preview

Inkline 0.3.5 removes the largest application-side source of terminal lag.
Libghostty's dirty-row metadata now updates a retained grayscale surface, so a
normal keystroke no longer allocates, rasterizes, converts, and compares the
whole display. On reMarkable 2, a dirty text row averaged 0.374 ms to render;
a dense 1840 × 1280 full frame averaged 554.340 ms.

Settings adds five RAM-only e-paper profiles. Fast uses the firmware Animation
mode and is the default; Balanced uses UI; Crisp uses Content; Mono favors
black-and-white text; Saver keeps the UI waveform but batches output longer to
request fewer updates. The old fixed 80 ms repaint delay is gone.

This release also adds a RAM-only minimum-contrast slider. It moves terminal
foreground gray toward black or white when a program chooses foreground and
background values that are too close, while leaving backgrounds and graphics
unchanged. The existing text-darkness control remains separate.

All nine host and ARM suites pass. Relevant renderer, session, and clipboard
suites also pass under AddressSanitizer and UndefinedBehaviorSanitizer. An
offscreen ARM probe loaded the stock 3.27.3.0 scene-graph plugin and successfully
selected its Mono, Animation, UI, and Content modes. Physical ghosting, waveform
feel, and battery behavior remain acceptance checks on the tablet.
