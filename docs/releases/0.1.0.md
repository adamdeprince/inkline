Inkline 0.1.0 is the first installable preview for **reMarkable 2 on firmware
3.27**, tested on **3.27.3.0**. It provides a local terminal with Type Folio input,
kitty graphics in RAM, and an initial sixel implementation.

Download **`inkline-rm2.tar.gz`** and **`inkline-rm2.tar.gz.sha256`** from the assets
below, then follow the [installation procedure](https://github.com/adamdeprince/inkline/blob/v0.1.0/docs/install.md).
The approximately 49 MiB ARM bundle contains the installer, uninstall script,
checksums, corresponding source archives, and licenses. Installation requires
SSH access to the tablet; no SDK, compiler, or third-party package manager is
needed. GitHub's automatic source-code archives do not include the binary.

After installation, press **Ctrl+Alt+T** on the tablet to open Inkline. Tap
**Quit**, press **Ctrl+Shift+Q**, or exit the shell to return to notebooks.
The shortcut listener is enabled at boot. The notebook interface remains the
default, and the terminal opens on request.

All five test suites pass on macOS and the tablet. Installer preflight, initial
installation and removal, a timed e-paper demo, and automatic return to notebooks
have been exercised. On-device launch and typing are confirmed with Type Folio.
The graphics suite measured zero process storage-write bytes during its image
tests; applications run inside the terminal can write their own files and caches.

This is a preview. Kitty Unicode placeholders, animation playback, some image
layering cases, and selection/clipboard tools remain unfinished. Sixel needs
further display-mode and scrolling work and is not yet advertised automatically.
External USB keyboard hardware/hotplug, additional layouts, reboot behavior, and
the modified mosh workflow still need acceptance testing. Other reMarkable models
and firmware outside 3.27 are not supported by this installer.
