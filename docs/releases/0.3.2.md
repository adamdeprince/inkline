# Inkline 0.3.2 preview

This update removes the keyboard zoom combinations and slows down pinch sizing
for finer control of terminal text.

- Neither Alt key intercepts `+`, `=`, `-`, or `_` for zoom. On the US Type Folio,
  **right Alt/Option + the minus key immediately left of Backspace** types `=`.
- Pinching has about half its previous proportional response and adjusts in
  **one-pixel steps**, within the existing **6–48 px** range. Settings retains
  its minus and plus buttons. Sizes apply across all six terminals, save after
  the gesture, and restore if the gesture is cancelled.
- With input method **Off**, the Folio's standalone accent keys produce literal
  punctuation. **Shift+6** types `^`, so `c^2` remains `c^2` instead of `ĉ2`.
  US-International still composes accents when selected. Pasted or committed
  Unicode is preserved.
- The startup guide and Settings help reflect the new controls.

Follow the [installation procedure](../install.md). Updating preserves open
terminals; **quit and reopen Inkline** to use this version.

All nine test suites pass on the development Mac and reMarkable 2. Regressions
cover printable punctuation with both Alt keys, firmware dead-key events,
literal caret input, deliberate accent composition, one-pixel pinch adjustments,
gesture cancellation, the 6–48 px limits, and independent terminal preservation.
The tablet's stock e-paper keyboard mapper was also exercised offscreen to
verify its US Folio events for equals and caret. Physical pinch feel and USB
layout acceptance remain checks on the actual keyboards and screen.
