# Inkline 0.4.1 preview

Global shortcuts now use **Opt + right Alt/Opt + letter**. On Type Folio, hold
the separate Opt key between Ctrl and Alt and the Alt/Opt key to the right of
the spacebar, then tap T. Ctrl is not part of this chord. On USB keyboards,
use Windows/Command (Super) plus right Alt.

The earlier Ctrl+Opt+Alt combination did not deliver a T keypress in the
physical Folio test. This release uses two modifiers. Plain Super, ordinary
Ctrl+Alt, and right Alt alone remain available to applications and Inkline's
existing shortcuts. Extra Ctrl, left Alt, Shift or a held Caps Lock excludes a
combination from the global launcher.

T remains permanent. Existing registered commands automatically use the new
prefix; no binding files need rewriting. Hold Opt+right Alt/Opt+Backspace for
two seconds for emergency recovery, which closes every terminal and opens a
fresh shell. Ordinary T launch preserves open terminals.

The installer restarts the global launcher immediately. Quit and reopen
Inkline to update its input handling and shortcut labels. The single
nine-language PDF manual describes the new chord.

Validation: host configuration, input and Settings tests pass. Tests on the
reMarkable cover the actual daemon event handler, Folio/USB key identities,
repeat suppression, held recovery, dropped events, registered-key suppression,
plain Super and Emacs Ctrl+Alt passthrough. Physical launch verification is
recorded separately in the device log.
