# Inkline 0.3.3 preview

The separate **Opt** key now provides **F1–F10** through **Opt + 1–0**.
On the Folio, this is the key between Ctrl and Alt.

**Right Alt/Opt + 0** now types `+` on the US Folio. Previously Inkline
intercepted the key as F10, preventing plus entry. **Right Alt/Opt + minus**
continues to type `=`. The other right Alt/Opt shortcuts are unchanged.

Function shortcuts preserve Ctrl, Shift, and Alt modifiers, autorepeat, and
kitty key releases. Ordinary left Alt input, numeric keypads, and native USB
function keys keep their normal behavior. The startup guide and documentation
show which modifier to use.

Follow the [installation procedure](../install.md). Updating preserves open
terminals; **quit and reopen Inkline** to use this version.

All nine suites pass on the host and reMarkable 2. Checks cover all ten function
keys, literal plus and equals, modifiers, repeats and releases, and a real shell
receiving `+` and F10. The tablet's stock keyboard mapper was exercised with
synthetic events to verify the Folio's distinct Opt and right Alt/Opt mappings.
Physical keyboard and USB layout acceptance remain.
