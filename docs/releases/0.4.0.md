# Inkline 0.4.0 preview

Global launchers now require **Ctrl+Opt+Alt**, leaving ordinary Ctrl+Alt available
to Emacs and other terminal programs. This includes the permanent T launcher,
registered commands, and the two-second Backspace emergency recovery chord.
On Type Folio, use the separate Opt key. On USB keyboards, use Windows/Command
(Super) together with Ctrl and Alt.

**Settings → Command shortcuts (page 2)** lets you assign commands to letters,
choose a terminal or native e-paper app, save changes, and confirm removal.
T cannot be reassigned or removed. Drafts stay in RAM; only explicit Save and
confirmed Remove update storage. The installed `~/inkline shortcut` command-line
tool manages the same bindings. Existing bindings keep their commands and
automatically use the new modifier combination.

The command editor supports quoted literal arguments. Request a shell explicitly
for pipes, redirection, variables, or glob expansion:

```sh
~/inkline shortcut register e emacs
~/inkline shortcut register d /bin/sh -c 'date | cat'
~/inkline shortcut list
~/inkline shortcut deregister d
```

Quit and reopen Inkline after upgrading to activate its new Settings page and
Ctrl+Alt passthrough. Installation preserves open terminals. The global daemon
adopts the new chord immediately. Ordinary Ctrl+Opt+Alt+T preserves sessions;
holding Ctrl+Opt+Alt+Backspace for two seconds closes them for emergency recovery.

The installer includes one updated PDF manual with all nine website languages.
The previous release's boot repair has now passed a fresh reboot check on
firmware 3.27.3.0; notebooks remain the default after boot.

Validation: macOS and ARM tests cover command parsing, shared UI/CLI bindings,
reserved T, confirmation, literal arguments, and Ctrl+Alt passthrough. ARM evdev
tests cover Folio Opt versus USB End/Super, held recovery, key repeats, dropped
events, and modifier reset. Tests run in tablet RAM beside active sessions.
Physical testing of the new three-modifier chords remains an acceptance check.
