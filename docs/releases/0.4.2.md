# Inkline 0.4.2 preview

Settings → USB (page 3) now switches the tablet between USB networking,
an outgoing keyboard, and host mode for a wired keyboard. Typewriter sends
Folio input to a connected computer, including committed Japanese, Chinese
and international input. Start is explicit; Escape pauses and releases keys.
Leaving Inkline restores USB networking, including after a crash.

Install the Python utility before using outgoing keyboard mode. Choose the
receiving computer's profile: US/ASCII, Mac Unicode Hex Input, Linux
Ctrl+Shift+U, or Windows with WinCompose. Windows needs Right Alt as Compose
and Unicode input enabled. Mac supports characters through U+FFFF. Host layout,
fonts and application support determine the text the receiving editor displays.

The installed `inkline-usb` and `inkline-type` commands share the UI's helpers.
UTF-8 files stream without a fixed size limit or temporary spool files.
Seekable files are fully validated before sending; pipes are checked as they
arrive and can be partially sent before a later error. Runtime state and the
preview stay in RAM, and helpers do not write Python bytecode caches.

```sh
~/inkline usb send-keyboard
~/inkline type --file notes.txt --profile windows --start-delay 3
~/inkline type --stop
~/inkline usb network
```

Global shortcuts now use **separate Opt + right Alt/Opt + letter**, including
the permanent T launcher and held Backspace emergency recovery. RightAlt means
the Alt/Opt key to the right of the spacebar; do not hold Ctrl. USB keyboards
use Windows/Command (Super) together with Right Alt. Ordinary Ctrl+Alt remains
available to Emacs, and plain Super remains available for personal bindings.
Settings → Command shortcuts (page 2) and `~/inkline shortcut` manage the same
bindings. T cannot be changed or removed.

The installer bundles one **98-page PDF manual**, built from LaTeX, with a
nine-language index and complete USB/typewriter instructions in every chapter.
Enable the USB web interface and leave notebooks open during installation to
import it into My files. Otherwise, enable the interface, quit Inkline and run
`~/inkline manual` from SSH. Installation preserves open terminal sessions;
quit and reopen Inkline to use the new UI.

Validation: macOS and ARM tests cover USB report encoding, files beyond 8 MiB,
chunked UTF-8/newlines, cancellation, sender locking, input methods, clipboard,
profile persistence, control requests and terminal navigation. ARM tests verify
stopping a real sender through its Linux pidfd. Disposable mode-switch fixtures
cover failed transitions, ownership checks and installation. Real tablet tests
verify outgoing/receiving/network mode transitions and network restoration after
normal and SIGKILL exits of isolated test services. Existing terminal sessions
are preserved. macOS discovered the keyboard but denied exclusive capture, so
no test characters were sent to the focused application. Physical chord use
and Windows/Linux application rendering remain separate acceptance checks.
