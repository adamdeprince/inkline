# Inkline 0.3.1 preview

This update fixes Alt-minus enlarging text on keyboards whose reported key
position conflicts with the minus symbol. Text sizing now ranges from **6 to
48 pixels**, using either Alt key, pinching, Settings, or `--font-size`.

- Drag **two fingers down** for older output and **up** toward the prompt.
  Pinches and scrolling are distinguished and locked for each gesture.
- Swipe **two fingers left/right** for the next/previous terminal. Each swipe
  changes one of the six slots; one-finger and pen drags still select text.
- Each terminal retains **500 physical scrollback lines in RAM**, excluding
  the live screen. Resizing also enforces the limit. Discarded references cannot
  move old graphics or selections onto unrelated text.
- Reclaim off-screen kitty and sixel graphics at 75% of their storage budgets,
  at 75% of the terminal allocation budget, or below 64 MiB of available system
  RAM. Keep visible graphics where possible and retain the existing hard caps.
  Unresolved kitty placeholder and relative-placement dependencies are handled
  conservatively; their existing renderer limitations still apply.
- Set **`HOME=/home/root`** in tablet sessions so bare `cd` works. Directly
  launched shells resolve their account's home directory when HOME is absent
  or empty, while preserving a supplied HOME.

Install using the [installation procedure](../install.md). The updater preserves
running terminals; quit and reopen Inkline to activate this version.

Validation covers conflicting minus/plus key positions, repeat/release behavior,
6 px rendering and persistence, rotated scrolling and swipes, gesture locking,
exact history retention and resize, off-screen image reclamation, fragmented
kitty transfers during cleanup, and real shells with missing or empty HOME.
All nine suites pass on the host and reMarkable 2. The seven affected host
suites also pass with address and undefined-behavior sanitizers. The tablet's
graphics tests record zero storage-write bytes. Physical gesture and Folio/USB
acceptance checks remain.
