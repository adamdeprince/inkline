# Inkline 0.3.4 preview

Settings now includes a **Text darkness** slider. Normal text already uses
pure black; the slider adjusts smoothed glyph edges to make small text appear
lighter or darker. 50% preserves the original rendering. Text positions,
terminal colors, backgrounds, and Kitty/sixel graphics are unchanged.

Drag with a finger, pen, or mouse, or focus the slider with Tab and use
Left/Right. Home/End selects the endpoints. The value applies to all six
terminals and stays in RAM through finger lifts and closing Settings. It never
writes a contrast preference to flash; closing Inkline resets it to 50%.

The tablet launcher now starts interactive `/bin/bash`, which reads
`/home/root/.bashrc`. Python and pip cache preferences belong in that file;
neither variable is supplied by Inkline. The separately updated Python utility
uses unmodified upstream CPython 3.15.0rc2. See [Python setup](../python.md)
for cache settings, `--no-compile`, certificates, and virtual environments.

All nine host and reMarkable 2 test suites pass. New checks cover lighter/darker
raster output, unchanged graphics and cell geometry, touch cancellation under
rotation, repeated adjustment without preference files, all-six-terminal
scope, and reset on restart. The stock Python package passes import-cache,
isolated-mode, venv/TLS, pip-cache and install-time compilation checks in RAM.
Physical finger/pen acceptance of the new slider remains to be confirmed.

The installer preserves running sessions. Quit Inkline and reopen it with
Ctrl+Alt+T to use the new controls and Bash startup behavior. Existing saved
keyboard, font-size, and input-method preferences are retained.
