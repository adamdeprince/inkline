# Inkline 0.4.5 preview

September 17, 2026

- The bottom bar now shows Escape, current battery state, Quit, and Settings.
  The page-history buttons were removed because right Alt/Option+Up/Down already
  sends PageUp/PageDown. Battery reads use Linux's read-only sysfs interface and
  refresh once per minute without writing to storage.
- The installed `inkline-battery` command reports percentage and charging state.
  Inkline shells use its compact percentage in a no-color prompt instead of the
  tablet's fixed `reMarkable` hostname. The installer preserves the rest of
  `.bashrc`, and uninstall removes only Inkline's marked prompt block.
- Right Alt/Option+Space now opens Settings, including when the bottom bar is
  hidden. Left Alt+Space opens the Unicode keyboard. Ctrl+Shift+B is no longer
  intercepted, so Emacs and other terminal programs receive it normally.
- Typewriter shows a high-contrast black `PAUSED · USB OUTPUT OFF` badge when
  live USB output is paused, with distinct indicators for connecting, live
  output, and whole-document sending.
