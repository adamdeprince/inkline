Noto Sans Mono CJK SC, from the official notofonts/noto-cjk repository.

Source: https://github.com/notofonts/noto-cjk/blob/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Sans/Mono/NotoSansMonoCJKsc-Regular.otf
SHA-256: `ec04cc376b34887cedbdf84074e2e226ed2761eeabdcb9173fc1dd7bfd153ef7`
License: SIL Open Font License 1.1, included in NotoCJK-OFL.txt.

Loaded privately by Inkline; no system font installation or font cache is needed.
The font covers Chinese, Japanese kana, and other CJK text. Glyph forms follow
the Simplified Chinese design. The original font is redistributed unchanged.

The Unicode keyboard and terminal also use three unmodified fallback fonts:

- Noto Sans Symbols 2 Regular 2.008, from the official notofonts/symbols
  release at commit `25b00f0d3f40873a005287514ba2a48558655314`.
- GNU Unifont 18.0.01 for broad Unicode Basic Multilingual Plane coverage.
- GNU Unifont Upper 18.0.01 for scripts and symbols above that plane.

The Noto symbol font provides higher-quality common symbols first; the two
Unifont files are last-resort bitmap-style faces. This is broad coverage, not a
claim that one font can contain every Unicode glyph. The exact hashes and
copyright holders are in `../../licenses/UnicodeFonts-NOTICE.txt`. These fonts
are also distributed under the SIL Open Font License 1.1 above and are loaded
privately without creating a system font cache.
