# Input-method data

`pinyin.dict` and `wubi.dict` are generated by `tools/gen-imdata.py` from
permissively-licensed upstream sources and loaded by GoblinView at
runtime (see `src/im.cc`). To regenerate:

    tools/gen-imdata.py --download

That fetches the sources, then writes the two `.dict` files. The fetched
sources are git-ignored; the generated `.dict` files are committed.

## Provenance and licenses

**pinyin.dict** — complete pinyin, one syllable per line, candidates
ordered common-first.

- Readings: [mozillazg/pinyin-data](https://github.com/mozillazg/pinyin-data),
  MIT License, which derives them from the Unicode **Unihan** database.
- Candidate frequency: Unihan `kHanyuPinlu` field. The Unihan database is
  distributed under the Unicode Data Files license (permissive, attribution).
- Common-tier bias: membership in the GB2312 level-1 block, a character
  encoding standard (not a licensed dataset).

**wubi.dict** — the Wubi 86 (王码五笔) shape table, one code per line,
candidates ordered by the upstream weights.

- [KyleBing/rime-wubi86-jidian](https://github.com/KyleBing/rime-wubi86-jidian),
  **Apache License 2.0** (五笔86极点 code table for Rime).

All three upstreams are compatible with GoblinView's license. The MIT and
Apache-2.0 sources require attribution, which this file provides; the
Unicode Data Files license likewise requires the attribution above. None
of the upstreams is GPL/LGPL: Rime's own `rime-wubi` and `rime-luna-pinyin`
are LGPL and are deliberately **not** used.
